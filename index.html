Tamagotchi Game

I coded a starting version of the Tamagotchi Game.

The main components are overlay, gui, server. It works by having the overlay and gui comunicate to each other with the server. The gui sends commands to the server and the server changes the overlay based on the request from the gui. The server can also recieve direct commands vie the terminal to trigger animation changes.

The overlay has overlay.html that is Calsifer itself that is in the overlay section in obs and overlay.js that does't the logic behind the overlay (decrese the hunger, mood and helth points).

Patchwork GitLab Repository

GitLab repository for Patchwork with a strict branch strategy. It's that no one can push any code in the main branch. This is done so there is always one stable version of the project and one unstable version where all development happens.

Different features are developed in different branches that merge into the side (unstable) branch and after validating that everything works and is stable enough is merged to the main (stable) branch.

This way there will always be a backup in case someone messes the repo by mistake.

Jira

For the group project I am the scrum master. We decided to use Scrum Agile because our client is not professional in any shape or form and introduces uncertainy (it took her 2 weeks to respond to out first email). Because of that we choose Agile becasue it’s very good work framework for these unpredictable clients.

The idea is to make a lot of stuff each sprint and display them to the client and deside from that what she likes and what she doesn’t like and work from there.

I decided that Jira is to be choosen for planning tool as Jira is designed for Agile Scrum and also a lot of big companies use it so it’s a great learning experience as it will come handy in the future. My team protested for a while because they are used to using Trello. But since we are not kids we now use Jira.

It took multiple sesions with Paul in order to figure out how to use that framework and I still think that improvements can be made.
